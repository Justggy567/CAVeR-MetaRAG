# RQ3 Main-700 and Replication-140 Data, Annotation, and Audit Package

## What This Package Includes

This folder is a self-contained evidence package for RQ3 diagnostic data, containing:

- The final frozen set of 700 main diagnoses (Main-700);
- A replication set of 140 entries extracted according to fixed rules without overlap with Main-700;
- Taxonomy and full annotation guidelines;
- A/B annotations and third-party arbitration tracks for legacy-700, final Main-700, and replication-140;
- Complete A/B review, arbitration, and frozen consistency evidence for the final Main-700;
- Filtering of replication candidates from 830 → 351 → 140, stratified sampling, selection crosswalk, and 211-entry reserve queue;
- Reproducible IAA, revision rates, independence checks, file hashes, and one-click verification scripts.

## Revision Rates

- Legacy-700: 206/700 (29.43%) retained without changing labels; 126/700 (18.00%) relabeled; 368/700 (52.57%) excluded; overall human intervention rate is 70.57%.
- Final A/B review and arbitration chain confirmation for Main-700: 700/700 frozen records all meet atomicity requirements. Incremental rewriting snapshots from the development phase have been omitted from the final release package, so this package does not attempt to recalculate historical rewrite counts.
- Replication-140: Final net change relative to the category/support certainty sampling file is 0; 8 hard-field disputes in A/B are all maintained with standard labels after C review.

## How the independent replication set was obtained

1. Start with 830 versioned candidates;
2. Compare each `source_dataset+source_id`, standardized question, context, and factoid with Main-700;
3. Exclude 479 that match at least one overlap rule with Main-700, retaining 351;
4. Form 28 strata by `category × support × source`;
5. Use fixed salt `rq3-replication140-v1` with candidate ID to compute SHA-256 ranking;
6. Take the top 5 from each stratum and enforce global context uniqueness to obtain 140 records; the remaining 211 become the reserve queue.
## One-Click Verification

Run in the root directory of this folder:

```powershell
python scripts/verify_package.py
```

The script only depends on the Python standard library, and it will recalculate data balance, IAA, arbitration coverage, revision ratios, Main/replication independence, the 351 candidate pool, and 140 samples, and check the immutable inputs against the code's `SHA256SUMS.txt`. The report generated by the verification script is not included in this hash list to avoid self-reference invalidation. On success, it outputs `verification_status: PASS`, with detailed results written to `reports/verification_results.json`.

If you only want to check without overwriting existing verification results:

```powershell
python scripts/verify_package.py --no-write
```
